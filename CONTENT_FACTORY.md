# B016 Content Factory

Pipeline:
GENERATE → SCHEMA VALIDATE → REFERENCE VALIDATE → SIMULATE → BALANCE CHECK → DE-DUPLICATE → PIXEL-DNA QA → GAMEPLAY QA → APPROVE → PACKAGE.

Content families:
materials, items, components, tools, weapons, armor, foods, plants, creatures, genomes, machines, structures, cultures, names, institutions, events, quests, ruins, dungeons, bosses, technologies, knowledge, sounds, animations, anomalies.

No generated content enters stable catalogs merely because generation succeeded. Every record needs provenance, version, maturity, tags, and validation status.
