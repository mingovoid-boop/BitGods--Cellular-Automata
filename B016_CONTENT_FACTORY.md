# B016 Content Factory

## Mission
Scale BitGods content without allowing generated quantity to corrupt simulation coherence, Pixel DNA, provenance, or gameplay readability.

## Pipeline
GENERATE → SCHEMA VALIDATE → REFERENCE VALIDATE → DE-DUPLICATE → SIMULATE → BALANCE → PIXEL QA → GAMEPLAY QA → APPROVE → PACKAGE

## Canonical domains
Materials, cellular components, items, plants, creatures, biomes, structures, machines, technologies, genetics, cultures, events, loot, quests, ruins, bosses, audio, animations and naming.

## Hard rules
1. Content is data-driven.
2. IDs are globally stable and unique.
3. References must resolve.
4. Historical loot preserves provenance.
5. Exotic/fictional rules are explicitly labeled.
6. Generated assets must obey Pixel DNA.
7. Quantity never substitutes for gameplay distinction.
8. New content cannot bypass the Transformation, Capability, Event, Knowledge or Network contracts.
9. Content promotion requires automated validation plus gameplay review.
10. Runtime integration must be separately verified; a valid catalog is not proof the game implements it.
