# B032 Playtest Alpha

B032 packages the accumulated BitGods work for a real human playtest. This is a process milestone, not a claim that every designed subsystem is production-complete.

## Freeze
Do not add a new foundational feature family before B033. First run the alpha, collect bugs/friction/performance evidence, and repair the highest-impact runtime problems.

## Truth
The bundle contains a playable browser baseline plus many progressively verified headless/scenario contracts and canvas adapters. A real target-machine playtest is still required.
