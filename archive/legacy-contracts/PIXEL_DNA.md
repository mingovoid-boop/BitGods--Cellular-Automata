# Pixel DNA v1

- Atomic detail: 1 px
- Detail increment: 2 px
- Structural module: 4 px
- UI grid: 8 px
- Small icons/items: 16x16
- Common objects: 24x24
- World tiles: 32x32
- Humanoid envelope: 32x48
- Major structures: 64x64+
- Integer scaling and nearest-neighbor filtering only.

## Shape grammar
- Square: material / terrain / data
- Circle: life / entity
- Hexagon: machine / system
- Diamond: event / energy
- Triangle: danger / attack
- Star: discovery / rarity

Generated content must inherit constrained VisualDNA: palette, geometry, materials, silhouette, ornamentation, architecture, animation, particles, civilization ancestry, and mutation seed.
