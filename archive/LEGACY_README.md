# B019 Browser Runtime
Run from this directory with:
`python3 -m http.server 8080`
Then open `http://localhost:8080`.

Controls: WASD/arrows. Gather wood and stone, move east until Mara's generated problem appears, then use Cell Craft with 1 wood + 1 stone. Save/load uses browser localStorage.

This is a minimal playable runtime proof, not the final engine.
