# BitGods development archive

This directory preserves material from the earlier B-series architecture and simulation work. It remains available for research and future extraction, but it is not part of the current 77.1 runtime.

See [`../VERSION_HISTORY.md`](../VERSION_HISTORY.md) for the complete evidence-labeled chronology across the original build train and modern playable releases.

## Contents

- `build-history/` — B016 through B034 manifests, design notes, validation outputs, scenarios, and run evidence.
- `legacy-contracts/` — superseded acceptance, simulation, content-factory, playtest, and visual-language documents.
- `legacy-data/` — retired schemas, catalogs, manifests, fixtures, and checksum records.
- `legacy-runtime/` — earlier split JavaScript and CSS prototypes.
- `legacy-tools/` — earlier Python, shell, and Windows validation or launch scripts.
- `LEGACY_README.md` — the prior repository overview retained verbatim.

## Archive policy

Archived files are historical evidence, not active release dependencies. Do not edit them to describe the current game. If an archived system is revived, migrate it into the current runtime deliberately and add coverage to `verify-runtime.cjs`.
