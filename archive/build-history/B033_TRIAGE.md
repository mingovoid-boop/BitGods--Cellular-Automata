# B033 Alpha Triage & Runtime Repair

## Evidence gate
- [ ] Launch Alpha on target machine
- [ ] Complete 30–60 minute route
- [ ] Capture blocker/major/minor/polish issues
- [ ] Record confusing and boring moments
- [ ] Record desired-but-impossible actions
- [ ] Verify save → close → reload
- [ ] Record FPS/stutters
- [ ] Attach screenshots/logs where useful

## Repair order
1. Launch/crash/save corruption.
2. Broken core loop.
3. Simulation/UI contradictions.
4. Pathfinding/performance.
5. Balance and usability.
6. Visual/audio polish.

## Freeze rule
No new foundational feature family until P0/P1 findings are closed or explicitly deferred.
