# B018 Alpha Integration

## Objective
Force the BitGods contracts through one executable end-to-end vertical slice.

## Current proof level
This bundle contains a **headless executable integration harness**, not a graphical game client.

The harness verifies:
- seeded authoritative world state
- resource mutation
- a cellular-machine state record
- agent problem → quest creation
- quest resolution → social/world consequence
- causal loot
- event lineage
- save/reload state integrity

Graphical rendering, real player controls, combat, full agent cognition, audio and large-scale simulation remain planned and are explicitly not claimed as verified.

## Required next proof
Replace headless adapters incrementally with real runtime modules while keeping the same acceptance scenario and truth table.
