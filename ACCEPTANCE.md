# Acceptance Gates

## Integration
- Deterministic checkpoints match for controlled runs.
- Save/load survives active war, weather, migration, economy, and agent activity.
- Resource conservation reports no unexplained duplication.
- Knowledge can spread, persist externally, be lost, and be reconstructed.
- Distant LOD preserves important identities and causal state.
- Macro outcomes can be traced to weighted causes.

## Player experience
A fresh one-hour run should naturally expose exploration, survival, inspection, loot, cellular crafting, invention, an NPC relationship, a generated problem, a consequential decision, and evidence of autonomous world continuation.

## Content
Every stable record must validate against schema, resolve references, pass duplicate checks, pass Pixel DNA checks where visual, and have an explicit maturity state.
